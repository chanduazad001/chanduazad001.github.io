# chanduazad001.github.io — portfolio hub

GitHub **user site**: served at the root `https://chanduazad001.github.io/`. Every lab repo is a separate project site under a sub-path, linked from here.

## What this repo is
- A single static `index.html` (no build step). `.nojekyll` disables Jekyll processing — keep it.
- Published directly from the default branch; any commit to `main` is live within minutes.

## Rules
- Keep it a lightweight landing page: who I am in one line, the four Lab cards (Solution, Cybersecurity, AI Platform, Projects → `/projects/`), and links. No heavy JS frameworks.
- Every link to a lab must be a relative or absolute path that exists. After editing, list each link and confirm the target repo/page exists.
- Inline CSS only, no external trackers or analytics.
- Accessibility: semantic HTML, alt text, sufficient contrast, works on mobile.

## Before committing
Open `index.html` locally and check all four cards render and link correctly.
